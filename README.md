# Stupid Editz - Video Editing Masterclass Platform

This repository contains the web app for **Stupid Editz**.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the app:
   ```bash
   npm run dev
   ```

3. Open `http://localhost:3000` in your browser.
